# Напоминалкин — связь сайта и Telegram

Код находится в этом каталоге:
- [Code.gs](Code.gs) — Telegram-бот (включая защиту от повторной обработки);
- [Backend.gs](Backend.gs) — общие напоминания в Google Sheets и отправка в Telegram;
- [App.html](App.html) — общий интерфейс для Насти и Саши.

## Как подключить к уже созданному Google Apps Script

1. В проекте Apps Script замените всё содержимое существующего **Код.gs** содержимым [Code.gs](Code.gs). Не стирайте Script Properties.
2. Через **+ → Скрипт** добавьте файл **Backend** и скопируйте туда код из [Backend.gs](Backend.gs).
3. Через **+ → HTML** добавьте файл **App** и скопируйте туда код из [App.html](App.html). Имя файла должно быть именно App.
4. В **Script Properties** должны остаться BOT_TOKEN, NASTYA_CODE, SASHA_CODE, WEB_APP_URL. Два кода должны быть разными, не менее 4 символов. Никогда не публикуйте токен и коды в GitHub или скриншотах.
5. **Вместо registerWebhook запустите startPolling** в выпадающем списке функций и дайте запрошенные разрешения. Эта функция удалит webhook, очистит очередь повторных сообщений и запустит проверку Telegram раз в минуту. Не запускайте registerWebhook после этого.\n6. Нажмите **Deploy → Manage deployments → Edit (карандаш) → Version: New version → Deploy**. Оставьте тот же URL /exec.
7. Откройте URL веб-приложения. При первой работе с задачами Apps Script создаст Google Spreadsheet «Напоминалкин - задачи» в Google Drive владельца. При первом запуске вручную выдайте проекту доступ к Google Таблицам (разрешение `spreadsheets`).
8. Введите свой персональный код. Создайте тестовое напоминание для второго человека. Если второй человек запустил Telegram-бота с его кодом, бот отправит ему новое сообщение.
9. Для напоминаний **в момент срока** потребуется отдельно установить таймер; текущая версия отправляет уведомление **при создании**, а не по сроку.

Общая версия открывается из [GitHub Pages](https://an8lomakina-svg.github.io/napominalkin/), кнопка ведёт к Google Apps Script. Вход пока по личному коду, **не через Google OAuth**. Использование бесплатное в пределах лимитов Google Apps Script и Sheets.

## Безопасность
Это простой личный проект для двух человек. URL Apps Script доступен всем, но чтение и изменение задач требует правильный персональный код. Не используйте ранее опубликованные короткие коды. Если токен бота когда-либо был на скриншоте, отзовите его через BotFather и сохраните новый только в Script Properties.
\n## Если бот бесконечно отправляет одно сообщение\nНемедленно запустите **stopWebhook** в Apps Script. Затем установите последнюю версию Code.gs из GitHub и запустите **startPolling** один раз. Повторный запуск startPolling заменяет существующий таймер, поэтому несколько параллельных таймеров не создаётся. После переключения бот отвечает на команды с задержкой до одной минуты.\n
