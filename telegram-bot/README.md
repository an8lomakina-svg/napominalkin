# Telegram-бот «Напоминалкин»

Бесплатный вариант на Google Apps Script. **Это исходный код, а не уже запущенный бот.**

## 1. Создать бота в Telegram
1. Откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`.
2. Задайте имя **Напоминалкин** и уникальный username, заканчивающийся на `bot`.
3. Скопируйте выданный токен. **Не присылайте его в чат и не записывайте в GitHub.**

## 2. Развернуть код
1. Откройте https://script.google.com/ и создайте новый проект.
2. Скопируйте код из [Code.gs](Code.gs) в редактор.
3. В **Project Settings → Script properties** создайте:
   - `BOT_TOKEN`: секретный токен из BotFather.
   - `NASTYA_CODE`: длинный случайный персональный код (не менее 20 символов).
   - `SASHA_CODE`: другой длинный случайный код.
4. Нажмите **Deploy → New deployment → Web app**. Execute as: **Me**; Who has access: **Anyone** (требуется для вебхука Telegram). Разрешите скрипту доступ к внешним запросам.
5. Скопируйте URL опубликованного веб-приложения (`https://script.google.com/macros/s/.../exec`) в свойство `WEB_APP_URL`.
6. В редакторе Apps Script выберите функцию **registerWebhook** и нажмите **Run**. Разрешите выполнение, если потребуется.

## 3. Подключить обоих
Каждый открывает в Telegram:
- `https://t.me/ВАШ_БОТ?start=КОД_НАСТИ`
- `https://t.me/ВАШ_БОТ?start=КОД_САШИ`

Не публикуйте эти ссылки: по ним привязывается чат. В Telegram нажмите **Start**. Затем можно отправить `/test`.

## 4. Что работает и что пока нет
Работает после запуска: привязка двух чатов, `/help`, `/id`, `/test`, отправка тестовых уведомлений из редактора Apps Script через **sendTestToBoth**.

**Автоматические сообщения о новых задачах ещё не подключены**: для этого нужна общая база задач (Firestore) и серверная интеграция с безопасным доступом к боту. Функция `notifyRecipient` подготовлена для доверенного серверного вызова. **Не вызывайте отправку через общедоступный веб-эндпоинт без проверки прав** — иначе посторонние смогут рассылать сообщения.

Для двух человек обычно можно обойтись бесплатными квотами Apps Script; они не гарантированы безлимитными.
