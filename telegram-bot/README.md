# Напоминалкин — связь сайта и Telegram

Код находится в этом каталоге:
- [Code.gs](Code.gs) — Telegram-бот (включая защиту от повторной обработки);
- [Backend.gs](Backend.gs) — общие напоминания в Google Sheets и отправка в Telegram;
- [App.html](App.html) — общий интерфейс для Насти и Саши.

## Как подключить к уже созданному Google Apps Script

1. В проекте Apps Script замените всё содержимое существующего **Код.gs** содержимым [Code.gs](Code.gs). Не стирайте Script Properties.
2. Через **+ → Скрипт** добавьте файл **Backend** и скопируйте туда код из [Backend.gs](Backend.gs).
3. Через **+ → HTML** добавьте файл **App** и скопируйте туда код из [App.html](App.html). Имя файла должно быть именно App.
4. В **Script Properties** должны остаться BOT_TOKEN, NASTYA_CODE, SASHA_CODE, WEB_APP_URL. Два кода должны быть разными, от 12 символов. Никогда не публикуйте токен и коды в GitHub или скриншотах.
5. Нажмите **Deploy → Manage deployments → Edit (карандаш) → Version: New version → Deploy**. Оставьте тот же URL /exec.
6. Откройте URL веб-приложения. При первой работе с задачами Apps Script создаст Google Spreadsheet «Напоминалкин - задачи» в Google Drive владельца. Возможно, потребуется отдельное разрешение доступа к таблицам.
7. Введите свой персональный код. Создайте тестовое напоминание для второго человека. Если второй человек запустил Telegram-бота с его кодом, бот отправит ему новое сообщение.
8. Для напоминаний **в момент срока** потребуется отдельно установить таймер; текущая версия отправляет уведомление **при создании**, а не по сроку.

Общая версия открывается из [GitHub Pages](https://an8lomakina-svg.github.io/napominalkin/), кнопка ведёт к Google Apps Script. Вход пока по личному коду, **не через Google OAuth**. Использование бесплатное в пределах лимитов Google Apps Script и Sheets.

## Безопасность
Это простой личный проект для двух человек. URL Apps Script доступен всем, но чтение и изменение задач требует правильный персональный код. Не используйте ранее опубликованные короткие коды. Если токен бота когда-либо был на скриншоте, отзовите его через BotFather и сохраните новый только в Script Properties.
